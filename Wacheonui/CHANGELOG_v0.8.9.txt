WACHEONUI v0.8.9 — Layer-safe weather cache and sync hardening

[한국어]
- 현재 지역에서 확인된 zoneUID 지문과 다른 지문으로 수신한 날씨가 현재 위상의 날씨로 선택되지 않도록 수정했습니다.
- 관측자별 최신 데이터 키에 위상 후보 지문을 추가하여 서로 다른 후보의 기록이 덮어써지는 문제를 방지했습니다.
- 파티/공격대 동기화 응답(W9S)은 최근 직접 요청한 nonce와 일치할 때만 수신하도록 개선했습니다.
- 오래된 동기화 요청 식별자를 자동 정리합니다.
- 기존 W7/W8/W9 수신 호환성을 유지합니다.
- 중요: NPC GUID의 zoneUID는 WoW Forever에서 검증된 위상 ID가 아닙니다. 실제 위상 자동 식별 및 위상 간 통신은 게임 내 추가 검증이 필요합니다.

[English]
- Prevents reports carrying a different zoneUID fingerprint from being selected as the current zone's weather when a local fingerprint is available.
- Separates per-observer latest records by tentative layer fingerprint.
- Accepts W9S group snapshot responses only for recent locally issued sync nonces.
- Expires outstanding synchronization request tokens.
- Preserves legacy W7/W8/W9 receiving compatibility.
- Note: Creature GUID zoneUID is NOT a verified WoW Forever layer identifier. Accurate automatic layer identification requires in-game validation.
