WACHEONUI v0.8.10 – Settings UI Cleanup (test build)
- Simplified the main settings window: observation, sharing, sync, manual weather report, map/panel settings.
- Removed developer/debug shortcuts (DB2, build, raw API capture, unknown records, ping) from the main settings window only.
- Kept underlying slash commands and existing networking and reporting logic unchanged.
- Retained network diagnostics as one compact button.
- No change to phase identification or network protocol in this build.

와천의 v0.8.10 – 설정 UI 정리 (테스트 빌드)
- 설정창을 관측, 통신, 동기화, 날씨 제보, 지도/패널 설정 중심으로 간소화.
- DB2 확인, 빌드 진단, 원본 API 기록, 미확인 기록, PING 버튼을 일반 설정창에서 숨김.
- 기존 명령어 및 통신·제보 기능 자체는 삭제하지 않음.
- 통신 진단은 단일 버튼으로 유지.
- 위상 판별 및 통신 프로토콜은 변경하지 않음.
